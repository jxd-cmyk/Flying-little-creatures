# Bug Dance Lite by JXD VibeLabs

Bugs dance across your screen. Freeware for Windows.

## Features

* 12 animated bug photos (© Jaroslav M. Soukup)
* Lives in the system tray — right-click the Bug\_Dance icon to control it
* Pause / Play
* Speed: Slow / Normal / Fast
* Size: Small / Medium / Large
* Transparency: 25 / 50 / 75 / 100 %
* Select which bugs to display
* Run at Windows start-up
* Always on the top
* Click-through overlay — does not block your mouse or work

## Requirements

* Windows 10/11
* The following files must be in the same folder as the program
(they are NOT bundled inside the exe):

  * Bug\_Dance.ico
  * Jaroslav.M.Soukup\_bugs\_1.png ... Jaroslav.M.Soukup\_bugs\_12.png
